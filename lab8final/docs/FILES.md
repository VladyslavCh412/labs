# Назначение каждого файла

Здесь перечислены исходники и материалы, которые публикуются в GitHub.
Сначала читайте README.md и BEGINNER_GUIDE.md. Не нужно изучать проверки
и исторические материалы раньше обычного сценария создания рейса.

Служебные папки .venv, node_modules, build и __pycache__ создаются программами.
Их не редактируют и не включают в этот справочник. Рабочие SQLite и ключи
также создаются локально; они описаны в data/README.md.
