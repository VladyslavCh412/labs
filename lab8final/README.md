# FleetFlow — підсумковий проєкт ЛР8

**Одна самостійна папка з кінцевим продуктом і результатами ЛР1–ЛР8.**
Фронтенд — TypeScript 7 зі strict-перевіркою; бекенд — FastAPI + SQLite.
Інші лабораторні й батьківська папка не потрібні для запуску, тестів і захисту.

## Запуск

Потрібні Python 3.13 і Node.js 24 з npm. Відкрийте **цю папку** у VS Code.

```powershell
python run.py setup
python run.py start
```

Панель: http://127.0.0.1:8000. Зупинка — Ctrl+C у терміналі.
Локальні облікові дані створюються в `data/LOCAL_ACCOUNTS.txt`.
Ролі: manager керує автопарком і рейсами; dispatcher планує, починає й завершує
рейси; viewer читає. Паролі випадкові та не включені до Git/пакета.
У VS Code є локальні налаштування: F5 — запуск, завдання tests/verification.

## Функції кінцевого продукту

- Автомобілі й водії, допуск до перевезення, статус технічного обслуговування.
- Маршрути та рейси: створення → початок → завершення зі збереженням пробігу.
- Захист від подвійного призначення ТЗ і подвійного нарахування пробігу.
- Три ролі, автентифікація, окремі права у Fleet і Trips.
- Незалежні SQLite, міграції, TTL-кеші та синхронізація через outbox/inbox.
- Вебпанель, журнал подій, сторінки рейсів, діагностика стану сервісів.

Усі HTTP-сервери слухають localhost. Початкові GPS/карти та зовнішній канал
сповіщень залишаються планом; їх стан, як і непідтверджені NFR,
відкрито наведено в архітектурній документації.

## Перевірки

```powershell
python run.py test
python run.py verify
python run.py benchmark
```

setup встановлює локальну `.venv` і npm-залежності. start/test/verify збирають
TypeScript. verify запускає контракти, структурні правила, domain coverage
>=95%, реальний HTTP p95 <=500 мс при 100 користувачах і негативний дослід.
Навантажувальні прогони запускати по черзі.

## Як вимоги циклу зібрані в одному продукті

| ЛР | Матеріали всередині цієї папки |
|---|---|
| 1 | Контекст, 15 термінів, 8 початкових сценаріїв, альтернативи, ADR-001/002 |
| 2 | Чотири шари, 4 доменні сутності, порти, DI, create/start/complete |
| 3 | Fleet/Trips, незалежні БД, HTTP-контракти, тайм-аути, gateway і workers |
| 4 | Strategy/Adapter/Factory/Observer, тести, before/after, вимірювання й історія |
| 5 | Модель даних, 4 міграції, кеші, read-only проєкція, ідемпотентні події |
| 6 | STRIDE, JWT/Argon2id/RBAC, план і результати навантаження до/після |
| 7 | Unit/integration/contract тести, fitness, CI, навмисне падіння gate |
| 8 | C4, весь ADR-журнал, NFR факт/ціль, борг, план, PDF і презентація |
