# FleetFlow — начните здесь

Это учебная система управления автопарком: автомобили, водители, маршруты и рейсы.
Итоговый проект объединяет требования лабораторных 1–8.

**Что можно показать:** создать автомобиль и водителя, составить маршрут,
начать и закончить рейс, увидеть пробег, события и работу кеша.

## Как запустить

Нужны **Python 3.13** и **Node.js 24 с npm**. SQLite отдельно устанавливать не нужно.

1. Скачайте репозиторий: зелёная кнопка **Code → Download ZIP** на
   [GitHub](https://github.com/VladyslavCh412/labs). Распакуйте архив.
2. Откройте в VS Code именно папку **lab8final**, в которой лежит этот README.
3. Один раз откройте **Terminal → New Terminal** и выполните:

   ```text
   python run.py setup
   ```

4. Дождитесь окончания установки. Затем выполните:

   ```text
   python run.py start
   ```

Вместо второй команды можно нажать **F5**. Для F5 установите расширения
**Python** и **Python Debugger** от Microsoft. Остановка — **Shift+F5**;
для запуска в терминале — **Ctrl+C**.

Без ввода команд: **Ctrl+Shift+P → Tasks: Run Task → FleetFlow: setup**,
дождитесь завершения, затем **F5**.

Если команда `python` не найдена, при наличии Python Launcher используйте
`py -3.13 run.py setup` и `py -3.13 run.py start`.

## Где что лежит

```text
lab8final/
  run.py          ← установка, запуск и проверки
  requirements.txt← зависимости Python; один список
  backend/        ← серверный код FastAPI
    api.py        ← отдаёт страницу и направляет запрос нужному сервису
    fleet/        ← автомобили, водители, пробег
    trips/        ← маршруты, рейсы, уведомления
  frontend/       ← страница, оформление и TypeScript
  data/           ← здесь создаются обе SQLite и локальные учётные записи
  tests/          ← автоматические проверки поведения
  checks/         ← проверки архитектуры и измерение скорости
  contracts/      ← согласованный формат межсервисных запросов и событий
  docs/           ← объяснения, диаграммы, ADR, отчёт и презентация
```

Внутри сервисов названия одинаковые по смыслу:
`api.py` принимает запросы, `domain.py` содержит правила,
`storage.py` работает с SQLite. У Trips сценарии собраны в `use_cases.py`.

## Где базы данных

После `setup` в **data** появятся **fleet.sqlite** и **trips.sqlite**.
Там сохраняются изменения. На GitHub эти файлы не загружаются:
у скачавшего проект они создаются автоматически. В папке опубликовано
[пояснение](data/README.md). Тестовые базы временные и не заменяют рабочие.

## Как проверить

```text
python run.py test
python run.py verify
```

`test` проверяет поведение. `verify` дополнительно проверяет архитектуру,
контракты, покрытие доменных правил и скорость HTTP, затем намеренно нарушает
правило в отдельной временной копии и проверяет, что нарушение обнаруживается.
Запускайте проверки по очереди.
