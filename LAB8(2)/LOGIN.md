# Дані для входу — FleetFlow

| Поле | Значення |
| --- | --- |
| Логін | `admin` |
| Пароль | `123123` |
| Роль | `manager` — керування автопарком і рейсами |

Обліковий запис створюється автоматично під час налаштування або запуску
проєкту. Для вже встановленої версії перезапустіть проєкт: відсутній `admin`
буде доданий, наявні облікові записи та дані збережуться.

Панель: http://127.0.0.1:8000. За замовчуванням вона працює без входу.
Ці дані також підходять для отримання JWT через `POST /auth/token`:

```json
{"username": "admin", "password": "123123"}
```

Це публічний демонстраційний обліковий запис для локального навчального
проєкту. Індивідуальні паролі інших ролей, ключ підпису JWT та бази даних
не публікуються в репозиторії.
