# Интерфейс — то, что видно в браузере

`index.html` задаёт расположение элементов. `styles.css` отвечает за внешний вид.
`src/app.ts` — TypeScript: обрабатывает кнопки, отправляет запросы серверу
и обновляет таблицы. `tsconfig.json` включает строгую проверку типов.

Не нужно редактировать `build/app.js`: это автоматически полученный JavaScript.
Папка build создаётся командами setup/start/test/verify и не хранится в Git.
Браузер исполняет JavaScript, а исходный код интерфейса остаётся TypeScript.

Из папки проекта: `python run.py setup`, затем `python run.py start`.
Для отдельной проверки типов из этой папки: `npm run typecheck`.
