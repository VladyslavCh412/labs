# Здесь приложение хранит данные

Здесь опубликованы две базы SQLite с данными проекта: **fleet.sqlite**
и **trips.sqlite**. Их можно скачать и открыть в программе для просмотра SQLite.
Приложение использует локальные копии этих файлов.

После `python run.py setup` рядом также создаются локальные учётные записи
и ключ. Содержимое папки:

| Файл | Простое объяснение |
| --- | --- |
| `fleet.sqlite` | База автомобилей, водителей, пробега и событий Fleet. |
| `trips.sqlite` | База маршрутов, рейсов, уведомлений и копий статусов Trips. |
| `users.json` | Локальные пользователи; пароли сохранены в виде хешей. |
| `jwt.key` | Случайный ключ для подписи токенов этого компьютера. |
| `LOCAL_ACCOUNTS.txt` | Данные локальных учётных записей. Публичный учебный вход: admin / 123123. |
| `audit.jsonl` | Журнал проверок доступа и изменений; появляется при работе. |

Обе базы SQLite сохраняют изменения между запусками. Их версии на GitHub —
снимок данных на момент последнего коммита; новые изменения в приложении
не отправляются туда автоматически. Если файлов баз нет, `setup` создаёт их.
Учётные записи, ключ подписи и журнал остаются локальными и не публикуются.
SQLite — обычный файл базы данных: отдельный сервер устанавливать не нужно.

Путь по умолчанию всегда относится к этой папке проекта, даже если команду
запустили из другой папки. Автоматические тесты используют временные базы,
чтобы не менять ваши автомобили и рейсы.

Fleet и Trips имеют собственные файлы. Они обмениваются информацией через API
и события; у них нет общей таблицы автомобилей или рейсов.
