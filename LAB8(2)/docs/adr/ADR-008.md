# ADR-008 Архітектурні перевірки у CI

Дата запису: 2026-10-27.
Статус: Прийнято в ЛР7.

Контекст: Ручний контроль імпортів і контрактів не запобігає регресії.

Альтернативи: Ручний review; локальні тести; обов’язковий конвеєр.

Рішення: AST, контракт consumer/provider, domain coverage ≥95%, окремий HTTP p95 gate.

Наслідки: Збірка може впасти через повільний runner; поріг не послаблювати, умови дослідити.
