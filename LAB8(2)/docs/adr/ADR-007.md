# ADR-007 Обмежена проєкція сторінки рейсів

Дата запису: 2026-10-27.
Статус: Прийнято в ЛР6.

Контекст: fetchall матеріалізує весь набір для першої сторінки, що підтверджено Server-Timing.

Альтернативи: Кеш усіх сторінок; LIMIT/OFFSET; нова БД.

Рішення: Обмежити вибірку SQL LIMIT та не дублювати JSON-перетворення готової проєкції.

Наслідки: p95 поліпшився; великий OFFSET і конкурентні записи потребують окремого аналізу.
