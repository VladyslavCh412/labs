8. ADR-003 — Межі сервісів і спосіб взаємодії
Поле
Рішення
Контекст
ЛР2 містила одне FastAPI-ядро; необхідні окремі доменні межі, API, події та дослід відмови.
Розглянуті альтернативи
Один модульний моноліт; Fleet + Trips; 5+ мікросервісів.
Прийнято
Fleet і Trips як два процеси з власними SQLite-файлами; gateway; синхронний HTTP GET + outbox TripCreated.
Наслідки
Незалежність даних, слабше зв’язування через події; натомість мережеві відмови, додаткові процеси й відсутність спільної ACID-транзакції.
Статус
Прийнято для навчальної архітектурної еволюції від ADR-001; не є промисловим розгортанням.
