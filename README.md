# FleetFlow — готовий проєкт ЛР1–ЛР8

Варіант 12: управління автопарком та маршрутами. TypeScript 7, FastAPI, SQLite; Python 3.13, Node.js 24.
Поточний застосунок — **lab8/**. Попередні каталоги збережено як етапи еволюції.

Фронтенд: TypeScript (`lab8/frontend/src/app.ts`, strict build). Бекенд: FastAPI + SQLite.

## Запуск

```powershell
python run.py setup
python run.py start
```

Вебпанель: http://127.0.0.1:8000. Зупинка: Ctrl+C у терміналі.
Локальні облікові дані створюються у `lab8/data/LOCAL_ACCOUNTS.txt` під час першого запуску.
`manager` керує автопарком і рейсами; `dispatcher` планує, починає та завершує рейси;
`viewer` читає. Паролі випадкові, JWT зберігається лише в пам'яті браузера.

У VS Code відкрийте `FleetFlow.code-workspace`. Запуск — F5 або завдання **FleetFlow: start**.
Налаштовано локальний Python `.venv`, тести та завдання перевірок.

## Перевірки

```powershell
python run.py test       # функціональні перевірки
python run.py verify     # контракти, fitness, coverage >=95%, HTTP p95 <=500 мс, негативний дослід
python run.py benchmark  # порівняння до/після на 20 000 рейсах
```

Навантажувальні перевірки запускайте по черзі. Історичні лабораторні тестуйте
окремо з їхніх каталогів: вони використовують однакові імена Python-модулів.
