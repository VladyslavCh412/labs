# ADR-009 Документація фактичної системи

Дата запису: 2026-10-27.
Статус: Прийнято в ЛР8.

Контекст: Початковий контекст мав GPS, карти та зовнішні сповіщення, яких немає у прототипі.

Альтернативи: Показувати задум як реалізацію; явно відділити факт і план.

Рішення: Три C4-рівні для поточного коду; таблиця всіх восьми NFR із невиміряними пунктами.

Наслідки: Чесна межа висновків; документацію оновлювати разом із кодом.
