# ADR-012: Єдиний відтворюваний пакет ЛР8

Дата: 2026-11-03. Статус: Прийнято. Уточнює ADR-009.

Контекст: README посилався на PDF і PPTX поза Git, а останній commit
видалив їх. Користувач запросив готовий проєкт і окрему публікацію ЛР8
у ветці lab8-complete, без підготовки нових звітів ЛР1–ЛР7.

Альтернативи: знову передавати файли окремо; зберегти тільки Markdown;
включити до ветки джерела, фінальний PDF/PPTX і санітизовані докази.
Обрано останнє. Винятки .gitignore дозволяють лише submission-файли ЛР8.

Рішення: одна точка запуску run.py, налаштування VS Code, актуальні
machine-readable OpenAPI, ARCHITECTURE.md з усіма 8 початковими NFR,
C4 L1/L2/L3, ADR, TEST_AUDIT, evidence та презентація <=10 хв.
Дані, ключі, паролі, venv і робочі БД не комітяться.

Наслідки: clone містить самодостатні матеріали; бінарні PDF/PPTX
збільшують Git. Джерела Markdown/діаграм дають змогу переглянути зміст.
Результат короткого benchmark не прирівнюється до production SLA.
Умова перегляду: регулярні великі медіафайли — перенести у GitHub Releases.
