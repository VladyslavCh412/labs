# ADR-006 Токени та права у власників

Дата запису: 2026-10-27.
Статус: Прийнято в ЛР6.

Контекст: ЛР5 дозволяла зміни без автентифікації; gateway можна обійти.

Альтернативи: Лише gateway; JWT у кожному сервісі; зовнішній IdP.

Рішення: Локальні Argon2id-облікові дані, HS256 JWT 15 хв і RBAC у сервісах.

Наслідки: Повторна перевірка; взаємна довіра ключу; TLS/IdP потрібні перед deployment.
