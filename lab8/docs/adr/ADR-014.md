# ADR-014: Самостійний кінцевий продукт в одній папці

Дата: 2026-11-03. Статус: Прийнято. Уточнює ADR-012/013.

Контекст: користувачу потрібна тільки підсумкова ЛР8, яка сама містить
усі реалізовані результати циклу. Кореневий launcher та посилання на
попередні папки робили комплект менш зручним для окремого використання.

Альтернативи: відкривати весь монорепозиторій; дублювати всі старі лабораторні;
зробити один самостійний каталог кінцевого продукту. Обрано останнє.

Рішення: run.py, локальна .venv, VS Code, ignore/attributes і standalone CI
належать цій папці. Сюди включено before/after для двох патернів, мінімальні
before-джерела для структурних вимірювань і справжню історію комітів.
Матриця вимог посилається на поточні шари/порти/сценарії та локальні докази.
Відокремлена копія без сусідніх лабораторних проходить збірку й pipeline.

Наслідки: каталог можна переносити як окремий проєкт. Історичні файли
у docs/refactoring/before не є другим застосунком і не виконуються.
Невиміряні початкові NFR лишаються явно позначеним боргом; організаційні
ролі команди й усний захист не підміняються програмними твердженнями.
Умова перегляду: поділ продукту на окремі репозиторії сервісів.
