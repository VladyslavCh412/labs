# Підтвердження рефакторингу в остаточному пакеті

`before/` — незмінні вхідні файли перед введенням чотирьох патернів,
узяті з наявного commit 46aa488. Вони потрібні тільки для AST-вимірювань,
не імпортуються і не запускаються застосунком. `history.json` фіксує
справжню послідовність комітів, включно з характеризаційними тестами до змін.

Після рефакторингу використовується поточний код цього проєкту.
`python verification/pattern_metrics.py` обчислює конкретні структурні
показники до/після; git та інші папки для цього не потрібні.
Результат — docs/evidence/pattern-metrics.json.
Діаграми двох складних випадків до/після — diagrams/patterns/.
